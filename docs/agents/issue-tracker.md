# Issue tracker used by team skills

ProjectMind tasks are tracked as GitHub Issues in
`LingweiXingzhi/projectmind-core`, as described in `docs/standards/TEAM_SOP.md`.
Use the `gh` CLI from this repository to read or create them. Link each task
branch and PR to its Issue. `to-spec` and `to-tickets` use the
`ready-for-agent` label for work that is ready to start. If that label does
not exist, create it before publishing a labelled Issue.

The third-party skills help prepare and execute tasks. They do not authorize
changes to the confirmed Project Model. Follow `AGENTS.md` and the two team
standards for that decision.
