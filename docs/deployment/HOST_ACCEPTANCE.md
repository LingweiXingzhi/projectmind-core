# 公网交付条件与执行顺序

域名可以最后购买。现在购买不会解决缺少真实服务器及访问条件的问题；软件准备不依赖购买域名。
本清单适用于本PR部署工具，不能代替真实主机验收。当前未部署公网。

| 阶段 | 必须具备或实际核验的条件 | 执行与证据 |
|---|---|---|
| 服务器交接 | Linux、systemd、管理员访问、实际IPv4/IPv6、所属云平台及区域、持久化磁盘 | 不把SSH密码/私钥写进仓库；管理员在正常授权渠道提供访问条件 |
| 基础主机 | Python3.10+及venv、Git、官方Caddy、独立caddy账号、时钟同步、容量 | `deployment.machine`私有报告；缺少projectmind账号可由安装阶段建立 |
| 网络 | 云安全组和主机防火墙80/443入站、SSH实际管理来源、允许模型HTTPS出站 | 8765只监听127.0.0.1；检查已有80/443监听者，避免与现有代理冲突；不能凭主机报告推断云规则 |
| 固定发布 | 私有仓库正常Git授权、完整历史、干净固定SHA、独立发布venv | 按HOST_READINESS安装；使用PR最终完整SHA，不把本地源码快照冒充上游完整clone |
| 私有数据 | 架构候选分支、代码来源、账户及权限、数据和源码分离、Git提交身份 | 以projectmind运行preflight；真实普通用户演练，不用root成功代替 |
| 域名 | 域名控制权、A到真实IPv4；确实可达才配AAAA | render-domain保留原数据源；两份配置域名一致；外部网络核验解析 |
| 启动 | 激活脚本冷备、固定版本链接、后端401、专用代理启动 | systemd状态、journal、主机重启后自启；ExecStartPre拒绝占位域名 |
| TLS | 公开CA签发、hostname验证、证书状态持久化及续期 | 公网host_smoke不加自定义CA/连接IP；本地内部CA报告不能作为公开签发结果 |
| 用户访问 | 两账户登录/CSRF/退出边界、中文页面及下载、不同网络第二设备 | CLI入口14项报告加真实浏览器验收；API检查不等于页面验收 |
| 恢复 | 私有账号/runtime/model.env/Caddy状态独立备份、数据冷备、异机私有副本 | 新目录恢复并读取历史；不恢复会话；相同代码登记路径/origin/HEAD，跨机重绑另做迁移 |
| 产品验收 | 真实模型调用、任务验证器、人审确认、共享记录及独立审查 | 保留各产品工作线的实际通过/阻塞；部署工具完成不等于模型/验证器完成 |

按照上表顺序推进，任一条件未核验均保留“待验收”，不把未知项目记为通过。
安装前可先生成无域名包；服务器安装与私有配置可先完成。公开激活须等真实域名及网络条件齐备。

## 故障处理

- 安装失败：保留目录和日志，查明依赖/磁盘/下载原因，不覆盖已有发布。管理员核对后明确处理失败的独立发布目录再重试。
- 升级备份失败：保留原current链接，应用停止；先修复并重新完成冷备，不跳过检查。
- 新版本启动、后端检查或代理重启失败：应用停止，保留新current和冷备；先查看日志，再确认旧版本兼容当前数据后显式activate旧SHA。
- 数据恢复：停止服务，只恢复到新目录；以服务用户核对数据/权限再采用恢复runtime，原数据始终保留。
- 疑似凭据泄漏：在对应服务撤销并更新私有配置，结束现有登录会话；故障证据分享前去除密码、Cookie、API Key与私有仓库地址。
