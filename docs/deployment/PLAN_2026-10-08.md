## 当前差距与本轮过程

1. **应用入口**：当前仅本机 Host/Origin，没有浏览器登录。
   提供显式公网模式、准确 HTTPS 来源、账号密码哈希配置、服务器会话/CSRF。
   登录后团队共享工作区；人审预览、确认与发布绑定到同一个浏览器会话。
   账号文件和状态在源代码外；不提供默认账号/密码，不把代理头当身份。
2. **完整 HTTP 接续**：复用当前路由与业务 service，使用生产 WSGI 服务运行现有 Handler，
   保持本地模式兼容。限制输入、连接和响应；配置来自服务器而非客户 JSON。
   公开浏览器只选择已登记的代码仓库，不能任意读取服务器路径。
3. **审查残留**：修复 context_pack 的复合缩写密钥名漏检，增加实际边界测试；
   仓库外 controller 问题单独保留，不把修复应用误写成修复全部审计项。
4. **产品联调**：验证已有项目/纯规划的保存、人审、发布和第二会话读取；
   复查新 D/UI 的实际差异后追加有依据的接续，版本身份不混用。
   未配置 AI 保持 NOT_RUN，测试夹具模拟的人审不批准真实团队项目认知。
5. **运行与上线材料**：准备 HTTPS 反向代理、进程守护、持久目录、备份/恢复和验收步骤。
   实际运行 WSGI 服务和 HTTP 测试，检查登录、错误来源、CSRF、跨会话发布、重启及仓库只读。
   无资源的公网 DNS、证书、不同网络第二设备验收明确 NOT_RUN。
6. **交付**：记录固定代码/树、实际命令与结果、范围/限制，上传新分支和 Draft PR；
   核对远端树、Draft 状态、main 未被本任务修改，再更新下一轮交接。

每阶段先核对差异与未完成项，再执行；只重复验证具体剩余风险。
持续推进有意义的缺口，额度受限时保留可接续证据，不为消耗额度发明需求。

## 验收条件

- 配置不完整拒绝启动；没有默认密钥/账号，没有未登录的代码与工作区 API。
- 准确公网 Host 与 Origin 被保留，登录和 CSRF 服务端验证；伪造 forwarded/身份无效。
- 不同浏览器会话不能确认/发布别人的预览，同一人重新登录也不能复用旧授权。
- 真实 WSGI 入口可完成本地隔离的草稿→人审→Git 版本，规划无代码 SHA 不伪造事实。
- 本地模式和已有接口仍通过相应回归；所有 NOT_RUN/环境缺口如实报告。
