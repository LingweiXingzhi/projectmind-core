### 复现

在已安装 requirements-deploy.txt 的 Python 环境运行完整 unittest。
自行核验 Caddy 可执行文件后，执行以下命令（输出必须是 Git 工作树之外的新私有目录）：

```sh
python verification/rehearse_public_https.py \
  --output /private/tmp/projectmind-https-new-run \
  --caddy /你的已校验工具目录/caddy
```

脚本只建隔离夹具，随机生成临时密码，不写死凭据，不安装系统 CA，不修改真实团队项目。
所有夹具服务退出后才复制并核验状态；浏览器不在该脚本验收范围。
