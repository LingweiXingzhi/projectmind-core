## 发现与本阶段目标

1. 当前 C 通过模块直调，登记能力不能准确反映真实调用；过程追踪投影没有传递工作区代码身份。
   复用 #60 的 C dispatcher / identity 校验，显式绑定真实 C，引擎调用保持规则候选与只读观察语义。
2. #60 新增模型提供方协议适配。复用服务端配置与 schema 检查；补齐真实传输边界：HTTPS 或明确本机 HTTP、禁止跟随重定向携带密钥、响应大小/异常控制。
   以本机协议夹具验证，未配置真实账号时不调用真实模型、不宣称真实 AI 闭环完成。
3. 保持部署登录、共享记录、D 任务、人工复核范围与私有存储。#60 的本地声明会话/D 控制器不直接覆盖公网真实账户适配。
