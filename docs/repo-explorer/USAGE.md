## 启动命令与地址

```bash
# 方式一：无地图启动（仓库浏览为主视图）——替换为你要浏览的仓库绝对路径
python app.py --repo "G:\path\to\any-repo" --port 8765

# 方式二：默认启动（本 checkout 的演示地图 + 仓库浏览入口）
python app.py --port 8765
```

浏览器打开启动时打印的地址（默认 `http://127.0.0.1:8765`）。方式一下顶部标签显示"仓库浏览 · 无人工地图"，仓库浏览是主视图；方式二下默认显示演示地图（明确标记"人工整理 · 演示图"），通过左侧导航第 4 项"仓库浏览"进入。

## 选仓库与看版本

1. 在"仓库浏览"视图输入仓库的本机**绝对路径**（相对路径会被拒绝），版本默认 `HEAD`，可填完整 40/64 位提交 SHA（分支名、短 SHA、标签一律拒绝）。
2. 打开后显示：仓库名、固定完整 SHA、覆盖统计（已跟踪/可浏览/跳过原因）。一次打开把 HEAD 解析为完整 SHA；目录、源码、符号都绑定这一个提交。
3. 未提交的修改和未跟踪文件不属于这个版本——它们不会出现在目录树里。

## 看目录 / 文件 / 符号

- 目录树：点击目录展开/收起；搜索框按仓库内相对路径过滤（清空即恢复）。
- 文件：点击文件名，正文带行号；超过 500 行分页，点"继续读取"加载下一页。
- 符号：文件面板上方显示该文件的定义（函数/类/方法，legacy 解析器只给定义行）；点击符号跳到对应行。**当前为 `legacy_code_facts` 过渡解析器：没有结束行、没有 docstring**，界面已如实标注；B 模块（`repo_index/symbols.py`）交付接入后自动切换为完整 AST 解析。
- 关系：显示"静态导入关系尚未接入解析器"——C 模块交付后才有导入/被导入视图；这不是空结果，是未接入状态。

## 比较两个提交

1. 打开仓库后出现"比较两个提交"卡片；输入两个**完整**提交 SHA（可在 Git 里用 `git log --format=%H` 取得）。
2. 结果列出新增/修改/删除/重命名（Git rename 检测）；点"打开新版"看目标版本源码，"打开旧版"看基准版本（删除的文件只能打开旧版）。文件面板会标注（新版）/（旧版）。
3. 这是静态文件差异，不包含语义级对比或运行调用图。

## 版本与限制（如实声明）

- 仅支持本地 Git 仓库的已提交内容；不执行目标项目的代码、不安装依赖、不为读取内容联网。
- 限额：一次索引最多 2000 个文件、单文件 1 MiB、总量 16 MiB；超限文件保留在树中并显示原因（`coverage.partial=true`）。预算按实际读取字节计费，含最终解码失败的文件。
- 二进制文件、非 UTF-8 文件名、symlink、submodule、编码声明错误的文件：保留目录入口并显示明确原因，不跟随 symlink/submodule 读取。
- 符号解析为过渡方案（`legacy_code_facts`）：只有定义行。导入关系未接入（C 未交付）。
- 新接口有 Host/Origin 来源校验（仅本机本服务）；旧地图接口在无地图模式下返回 `MAP_REQUIRED`，地图模式行为与基线完全一致。
- 无地图实例浏览仓库时**不会**在目标仓库创建 Worklog/Continuity 数据库。
- 多语言：非 Python 文件可浏览文本，但无符号/导入解析，界面如实显示。
- 已知性能取舍：目录树全量渲染，未做虚拟化（上限 2000 文件内可接受）。
