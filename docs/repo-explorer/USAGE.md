## 启动命令与地址

```bash
# 方式一：无地图启动（仓库浏览为主视图）——替换为你要浏览的仓库绝对路径
python app.py --repo "G:\path\to\any-repo" --port 8765

# 方式二：默认启动（本 checkout 的演示地图 + 仓库浏览入口）
python app.py --port 8765
```

浏览器打开启动时打印的地址（默认 `http://127.0.0.1:8765`）。方式一下顶部标签显示"仓库浏览 · 无人工地图"，仓库浏览是主视图；方式二下默认显示演示地图（明确标记"人工整理 · 演示图"），通过左侧导航第 4 项"仓库浏览"进入。

## 选仓库与看版本

1. 在"仓库浏览"视图输入仓库的本机**绝对路径**（相对路径会被拒绝），版本默认 `HEAD`，可填完整 40/64 位提交 SHA（分支名、短 SHA、标签一律拒绝）。
2. 打开后显示：仓库名、固定完整 SHA、覆盖统计（已跟踪/可浏览/跳过原因）。一次打开把 HEAD 解析为完整 SHA；目录、源码、符号都绑定这一个提交。
3. 未提交的修改和未跟踪文件不属于这个版本——它们不会出现在目录树里。

## 看目录 / 文件 / 符号

- 目录树：点击目录展开/收起；搜索框按仓库内相对路径过滤（清空即恢复）。
- 文件：点击文件名，正文带行号；超过 500 行分页，点"继续读取"加载下一页。
- 符号：文件面板上方显示该文件的定义（类/函数/异步函数/方法，`parser="python_ast_v1"`），每项带起止行；点击符号跳到对应行。解析失败或非 Python 文件如实标为 `parse_error`/`unsupported`，不伪装为空结果。
- 关系：显示该文件的静态导入，每条带 `resolution` 结果——唯一目标显示解析到的相对路径并可点击打开；多个候选显示为"待确认"；无候选显示"未解析"。下方列出被依赖（仅来自成功解析且解析到本文件的记录），并显示导入扫描覆盖（`已扫描/总数`）。部分文件解析失败或被预算跳过时，界面如实说明反向依赖只在已解析范围内成立，不称完整扫描。

## 比较两个提交

1. 打开仓库后出现"比较两个提交"卡片；输入两个**完整**提交 SHA（可在 Git 里用 `git log --format=%H` 取得）。
2. 结果列出新增/修改/删除/重命名（Git rename 检测）；点"打开新版"看目标版本源码，"打开旧版"看基准版本（删除的文件只能打开旧版）。文件面板会标注（新版）/（旧版）。
3. 这是静态文件差异，不包含语义级对比或运行调用图。

## 版本与限制（如实声明）

- 仅支持本地 Git 仓库的已提交内容；不执行目标项目的代码、不安装依赖、不为读取内容联网。
- 限额：**内容索引**最多 2000 个文件（即符号/导入解析与源码可浏览范围），单文件 1 MiB、总量 16 MiB；目录树展示的是该提交的完整清单，条目数可以超过 2000——被预算跳过的文件保留树入口并显示原因（`coverage.partial=true`）。预算按实际读取字节计费，含最终解码失败的文件。
- 二进制文件、非 UTF-8 文件名、symlink、submodule：保留目录入口并显示明确原因，不跟随 symlink/submodule 读取。
- 解码范围：PEP 263 编码声明只对 `.py`/`.pyi` 生效；其它文本按 UTF-8 解码。非 UTF-8 文本文件保留目录入口并显示"编码不支持或解码失败"，不隐藏原因。
- 符号与导入解析均为纯 AST 静态解析（不执行目标源码）：符号给出词法定义与源码范围，导入关系给出候选与解析状态；不推断运行时归属、动态导入或调用链。
- 导入解析的已知取舍：包深度按**搜索根**度量（`src/core/mod.py` 的搜索根是 `src`、包是 `core`、d=1），相对导入仅允许 `1 ≤ level ≤ d`，越出顶层包或无包语境一律判为未解析——即使仓库根/搜索根内恰好存在同名文件也不命中；绝对导入在仓库根与该文件自身搜索根下查找。`from pkg import name` 不跨文件推断属性/重导出，只连接真实存在的源码 blob；命名空间包（无 `__init__.py`）只有目录、没有源码入口，如实判为未解析。每条未解析记录都给出原因，不猜造目标。
- 新接口有 Host/Origin 来源校验（仅本机本服务）；旧地图接口在无地图模式下返回 `MAP_REQUIRED`，地图模式行为与基线完全一致。
- 无地图实例浏览仓库时**不会**在目标仓库创建 Worklog/Continuity 数据库。
- 多语言：非 Python 文件可浏览文本，但无符号/导入解析，界面如实显示。
- 已知性能取舍：目录树全量渲染，未做虚拟化（树条目不受 2000 内容索引上限约束，超大仓库下首版可能变慢）。
