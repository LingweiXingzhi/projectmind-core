# 共享 API 与老师演示额度 · 2026-10-08

用户目标：在 AI 接入页面填写 URL、API Key、模型即可使用；老师不需要自己的 API，使用实例共享的 API；提供 token 限额供简单展示。

最新澄清：必须有“个人 API”与“老师演示共享 API”两个独立模式。个人配置不能覆盖共享配置；公网个人配置绑定已认证账号，本机个人配置绑定浏览器会话而不是操作者声明。共享修改只允许运行者明确登记的配置账号；演示入口隐藏配置表单，所有演示调用强制选择共享模型。

实施顺序：
1. 服务端私有配置和持久化总额度账本，不写 Git，不回传密钥。
2. 复用现有请求生命周期，把生成、纠正和解释全部接入预算；发出前预留，可信 usage 结算，超时/未知用量保守扣除。
3. 页面配置、保存、测试已保存连接、剩余额度；测试也是实际模型请求并计入额度。
4. 本地仅接受同源写会话；公网老师使用共享配置，只有运行者明确登记的配置账户能改模型/额度。
5. 并发、重启、失败、权限、密钥不回显、模型输出上限的回归和原生浏览器操作。
6. 不将合成 API 当作真实供应商或真实 AI 效果；可用密钥仍需用户在页面自行填写。

默认演示总额度 50000、单次输出 2048，运行者可调整。账本是应用侧请求预算，不是货币账单；保存配置不会自动重置已用额度。
正式 Model 不发布，main 不合并。
